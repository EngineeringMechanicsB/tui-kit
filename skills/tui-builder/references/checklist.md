# 交付前检查清单

## A. 代码

- [ ] 依赖尽量少：标准库 + rich（+ requests/paramiko 业务需要）
- [ ] 业务逻辑与界面分离：核心函数返回 `(ok, detail)`，不直接 print
- [ ] 所有会失败的地方都有明确提示，不静默
- [ ] `--help` / `--dry-run` / `--no-color` 至少给一个
- [ ] 有 `--skip-*` 之类的分段开关，现场排查方便
- [ ] 默认值写在 argparse 里，交互菜单与命令行参数共用同一份
- [ ] 中文注释，函数短小

## A2. 配置与自动化

- [ ] 所有可变参数都进了配置文件，代码里没有写死的 IP/密码/路径
- [ ] 首次运行自动生成配置，且每项带中文注释
- [ ] 配置文件被改坏时先备份再重建，不直接覆盖
- [ ] `--auto` 全程不读输入；`--steps` 可选步骤
- [ ] `--dry-run` 不连接设备
- [ ] 失败时退出码非 0
- [ ] 每次运行有日志；需要时生成 md/html/json 报告
- [ ] 报告文件名带时间戳 + 目标，多台不冲突

## B. 终端体验（Win10/11）

- [ ] 进场调用了 `enable_vt()`
- [ ] Console 宽度减 1（用 `make_console()`）
- [ ] 颜色只用主题名（`ok/err/warn/info/title/muted`），没有 `blue` / `dim`
- [ ] 状态同时有颜色 + ASCII 标记（色盲/黑白打印也能读）
- [ ] Live 里没有 `print()`
- [ ] 长任务有进度反馈；短任务不闪屏
- [ ] 出错后不会停在半截界面
- [ ] Ctrl+C 能干净退出（`KeyboardInterrupt` 有处理）

## C. Win7 专项

- [ ] 用 `--no-vt` 或真机跑过，无 ANSI 残留、无方框
- [ ] 表格在 80 列宽度下不错位
- [ ] 中文宽度用手写对齐时按 2 列算
- [ ] 管道输出 `app.exe > out.txt` 中文不乱码
- [ ] `input()` 有 `EOFError` 兜底
- [ ] 配置文件按原编码写回（UTF-8 / GB2312 不互相污染）

## D. 打包

- [ ] Python 3.8.10（x64 + x86 各一套）
- [ ] PyInstaller 5.13.2 + setuptools<81
- [ ] spec 里 `binaries=UCRT`（downlevel 目录）
- [ ] `build_win7.py --check` 通过
- [ ] 两个架构都打了
- [ ] exe 在**裸 Win7**（未装 VC++）上跑过
- [ ] 数据文件能通过 `_MEIPASS` 读到
- [ ] 体积在预期范围

## E. 文档

- [ ] README 写明：哪个 exe 给哪个系统、默认参数、依赖
- [ ] 已知限制写清楚（比如"只支持 Win10/11"）
- [ ] 备份了旧版本 exe
